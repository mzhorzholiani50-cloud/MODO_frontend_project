# MODO — კრეატიული ნამუშევრების გალერეა

**MODO** არის Front-end-ის სასწავლო პროექტი — თანამედროვე, მრავალგვერდიანი და რესპონსიული ვებსაიტი ქართული ინტერფეისით. პროექტი საშუალებას აძლევს მომხმარებელს დაათვალიეროს დიზაინის ნამუშევრები, მოძებნოს და გაფილტროს ისინი და შეინახოს რჩეულები.

**GitHub რეპოზიტორია:** https://github.com/mzhorzholiani50-cloud/MODO_frontend_project

## გამოყენებული ტექნოლოგიები

- **HTML5:** სემანტიკური სტრუქტურა (`header`, `nav`, `main`, `section`, `article`, `footer`, `form`, `dialog`).
- **CSS3:** Flexbox, Grid, CSS ცვლადები, ანიმაციები, ადაპტიური განლაგება და media queries.
- **Vanilla JavaScript:** DOM-თან მუშაობა, მოვლენების დამუშავება, ფილტრაცია, მონაცემების შენახვა და ფორმის ვალიდაცია.
- **Git/GitHub:** ვერსიების კონტროლი და პროექტის კოდის საჯარო რეპოზიტორიაში გამოქვეყნება.

Framework-ები და დამატებითი JavaScript ბიბლიოთეკები საჭირო არ არის.

## ძირითადი ფუნქციები

1. **ძიება და ფილტრაცია:** ნამუშევრების ძიება ტექსტით და კატეგორიით, შედეგების დალაგება.
2. **რჩეულები:** ნამუშევრების მონიშვნა და `localStorage`-ში შენახვა, რათა გვერდის განახლების შემდეგაც შენარჩუნდეს.
3. **დეტალური დათვალიერება:** პროექტის მოდალური ფანჯარა, რომლის დახურვა შესაძლებელია კლავიატურითაც.
4. **ინტერაქტიული ელემენტები:** მთავარი გვერდის კარუსელი, მობილური მენიუ, FAQ და ღია/მუქი თემა.
5. **ფორმის ვალიდაცია:** აუცილებელი ველებისა და ელფოსტის ფორმატის შემოწმება და უკუკავშირის ჩვენება.
6. **რესპონსიული დიზაინი:** განლაგება მორგებულია კომპიუტერის, პლანშეტისა და ტელეფონის ეკრანებზე.

## გაშვების ინსტრუქცია

1. გახსენი [რეპოზიტორია](https://github.com/mzhorzholiani50-cloud/MODO_frontend_project).
2. აირჩიე **Code → Download ZIP** და გაშალე ფაილები.
3. გახსენი `index.html` ბრაუზერში.

ალტერნატიულად, გახსენი საქაღალდე VS Code-ში და გაუშვი **Live Server**, ან ტერმინალში გამოიყენე:

```bash
python3 -m http.server 8000
```

შემდეგ გახსენი `http://localhost:8000`.
