# MODO — კრეატიული ნამუშევრების გალერეა

**Front-end-ის პრაქტიკული პროექტი** — სრულად შესრულებულია **HTML5, CSS3 და Vanilla JavaScript**-ით. თანამედროვე, მრავალგვერდიანი და რესპონსიული ვებსაიტი ქართული ინტერფეისით.

> ეს არის დემონსტრაციული სასწავლო პროექტი. ნამუშევრები და კლიენტების სახელები გამოგონილია. საკონტაქტო ფორმა შეტყობინებებს მხოლოდ ბრაუზერის `localStorage`-ში ინახავს და რეალურ წერილებს არ აგზავნის.

## 🚀 გაშვება

1. გადმოწერე/გაშალე პროექტის ZIP ფაილი.
2. გახსენი `index.html` ბრაუზერში — დამატებითი ბიბლიოთეკების დაყენება არ არის საჭირო.
3. საუკეთესო გამოცდილებისთვის გამოიყენე VS Code-ის **Live Server**, ან ტერმინალში პროექტის საქაღალდეში გაუშვი:

   ```bash
   python3 -m http.server 8000
   ```

4. გახსენი `http://localhost:8000`.

## ✨ JavaScript-ის ფუნქციები

- ნამუშევრების **ცოცხალი ძიება** სახელის, კლიენტის, აღწერისა და კატეგორიის მიხედვით.
- **კატეგორიის ფილტრი**, **დალაგება** (ახალი/ძველი/A–Z/Z–A) და **რჩეულების ფილტრი**.
- **რჩეულების დამატება/წაშლა** და ბრაუზერში შენახვა `localStorage`-ით (განახლების შემდეგ არ იკარგება).
- ნამუშევრის **დეტალური მოდალური ფანჯარა** (`<dialog>`), დახურვა Escape-ით ან კლიკით.
- მთავარ გვერდზე **კარუსელი** წინ/უკან ღილაკებით.
- **ღია და მუქი თემა**, არჩევანის შენახვით.
- **მობილური მენიუ**, კლავიატურით მართვა და ARIA ატრიბუტები.
- **საკონტაქტო ფორმის ვალიდაცია**: სახელი, ელფოსტა, თემა და შეტყობინება; შეცდომები და წარმატების შეტყობინება.
- **FAQ** გახსნა/დახურვა HTML `<details>`-ის საშუალებით.
- შედეგების მრიცხველი, ცარიელი შედეგის შეტყობინება და ფილტრების გასუფთავება.

## ♿ ადაპტაცია და ხელმისაწვდომობა

- მობილური მოწყობილობებისთვის ბადე გადადის 3→2→1 სვეტზე.
- ვიზუალურად გამოკვეთილი keyboard focus, `aria-label`, `aria-pressed`, Live Regions და `skip-link`.
- `prefers-reduced-motion` მხარდაჭერა.
- სურათები არის ლოკალური ორიგინალური SVG — არ ირღვევა მესამე მხარის საავტორო უფლება.
- ძირითადი შიგთავსის ხელმისაწვდომობა JavaScript-ის შეცდომის გარეშე სანავიგაციო დონეზე; დინამიკური გალერეა საჭიროებს JS-ს.

## 🔧 GitHub-ზე გამოქვეყნება

პროექტს აქვს ლოკალური Git რეპოზიტორია და commit ისტორია (თუ ZIP-ში `.git` საქაღალდეა). GitHub-ზე რეალური რეპოზიტორიის შექმნას/ატვირთვას სჭირდება შენი GitHub ანგარიში.

1. შექმენი GitHub-ზე **ახალი ცარიელი repository** (README-ის ავტომატური დამატების გარეშე), მაგალითად `modo-gallery`.
2. ტერმინალში პროექტის საქაღალდიდან გაუშვი:

   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/modo-gallery.git
   git branch -M main
   git push -u origin main
   ```

   თუ `.git` არ გაქვს, ჯერ გაუშვი `git init`, `git add .`, `git commit -m "Build MODO responsive frontend"`.

3. GitHub → **Settings → Pages → Build and deployment** → **Deploy from a branch** → `main` / `(root)` → Save.
4. მიიღებ ვებსაიტის ბმულს: `https://YOUR_USERNAME.github.io/modo-gallery/` (გამოქვეყნების შემდეგ).
